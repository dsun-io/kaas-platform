# 报价成本 / 保险 / 计量口径（2026-10-18 用户确认）

> 本文记录本轮用户明确下达的报价口径，避免后续会话再按“产品默认成本”实现。

## 1. 成本

- **所有产品都必须由报价人在报价页手动填写成本**；
- 产品定义里的成本字段只作为内部变量，**不得自动套用到报价行**；
- 历史报价成本只作为参考显示，必须由用户点「应用参考成本」才填入；
- 批量报价同样必须手填成本；
- 成本未填时不能算价、不能保存。

## 2. 保险

- 只对 **CIF / DAP / DDP** 生效（CFR 及以下不含保险）；
- 公式：`保险费 = 整单 EXW 货值 × 1.1 ÷ 1000`，**最低 15 美元**；
- **整单只算一次**，再按各报价行的 EXW 货值比例分摊到行；
- 货值口径：整单 EXW 不含税金额（报价币种）；
- 前端两轮计算：第一轮保险按 0 取得各行 EXW；第二轮把分摊后的美元保险按下发；
- 模板字段：`insurance.formula = insurance_of_exw`，`mode = per_shipment`（金额由前端算好后下发）。

## 3. 船公司

- CFR / CIF / DAP / DDP 报价时必须选择船公司；
- 选项写死，格式「中文名-英文缩写」，如 `马士基-MSK`、`地中海航运-MSC`、`中远海运-COSCO`、`达飞轮船-CMA CGM` 等；
- 船公司随报价单保存。

## 4. 米 → 卷

- 客户按米要货时，报价行可填「客户需求（米）」；
- 系统按 `1 卷 = 多少米` 自动换算：`卷数 = 总米数 ÷ 每卷米数`，**小数进一**；
- 每卷米数取产品数量区的卷长；勾花网这类没有数量区参数的取规格 `len_m`。

## 5. 税务字段归属

- **企业级**：销项增值税、杂税 → 税务管理的「企业税档」；
- **产品级**：进项增值税、出口退税率 → 税务管理的「产品税率」，一个产品一条；
- 报价时按行产品自动带出进项/退税，快照写 `tax_snapshot.product_taxes`。
