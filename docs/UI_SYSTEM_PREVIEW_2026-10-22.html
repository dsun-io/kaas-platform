三、页面范式

ListPage 标准列表

PageHeader + FilterBar + DataTable + PaginationBar；搜索防抖、切筛选不闪骨架、空态三分支

Detail 详情

默认右侧抽屉 480/560；深链需求才用独立页；禁止行内展开

Edit 编辑

≤6 字段用对话框；长流程用独立页/向导；pending 中禁关闭

FormPage 表单页

FormField + 脏检查导航拦截 + 错误定位到字段

Workbench 工作台

左右分栏、右侧汇总 sticky；批量参数与单条同源

占位页

建设中徽章 + 说明；禁止假数据；纯静态去 use client

五、交互合约（六条）

1. 异步操作

  • pending 禁用 + 文案
  • 失败必 onError → toast
  • 成功有反馈 + 正确 invalidate key
  • 批量成功清空选择

2. 危险操作

  • 对外生效 / 不可逆 / 批量 / 影响下游
  • ConfirmDialog + 后果文案
  • pending 禁关闭
  • 后端 403/409 原因透出

3. 三态

  • 加载：LoadingBlock
  • 错误：ErrorState + 重试
  • 空：EmptyState 分两种
  • 失败 ≠ 空态

4. 详情 / 编辑

  • 详情默认抽屉
  • 编辑默认对话框
  • 轻量折叠可保留
  • 例外需注释理由

5. 筛选与导航

  • 筛选/分页/tab 入 URL
  • tab 不丢状态
  • 侧栏 prefetch=false
  • 未开通工位双路径拦截

6. 可访问性

  • icon-only 必 aria-label
  • label 关联 / aria-invalid
  • 可展开行键盘可达
  • 1366×768 无横向溢出
