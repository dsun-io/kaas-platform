# 单证编辑体验升级方案（A5 · 2026-10-21 提案，待用户过目）

> 状态：**方案稿（未施工）**。背景见 `docs/TODO.md` A5 与 `TRADE_DOC_HARDENING.md`（A7 已完成）。
> 目标：让"开一张单 + 改一张单"从「逐字段手填」变成「带默认、可批量、会校验」，同时不破坏 A7 的
> 事实层/一致性/签发闸门口径（**所有编辑仍落 payload，不绕过事实与确认流程**）。

---

## 1. 现状与痛点（基于现有实现，非想象）

| 场景 | 现状 | 痛点 |
|---|---|---|
| 新建单证 | `doc-create-form` 从上游（报价/订单）带入 + 手工补 | 同一客户/同产品反复填相同条款；错误默认值（如付款方式）靠人记 |
| 改行项 | 单行编辑（已支持） | 30 行报价要逐行改规格/单价；改产品后规格不联动 |
| 条款类字段 | 自由文本（`custom.payment_terms` 等） | 同一条款十种写法 → A7 一致性只能标"冲突"，不能引导统一 |
| 金额 | 单一来源推导（A7 已强制） | 只读展示，缺"改一个数看整单影响"的即时反馈 |
| 中英双语 | `text_zh/text_en` + A13 翻译入口 | 英文栏常留空，靠导出前人工补 |

## 2. 方案（三条工作流，按投入产出排序）

### W1 · 条款模板（先做，收益最大、风险最低）
- **做什么**：把常用条款（付款方式/装运条款/检验/索赔/不可抗力/仲裁）做成**租户级条款库**：
  - 设置页 `settings/company-profile` 增「条款模板」区：名称 + 中文 + 英文 + 适用单证类型；
  - 单证编辑时条款字段变为「下拉选择模板 / 自定义」，选中即回填中英双语（**不覆盖已手工改过的字段**，需二次确认）；
  - 与 A7 一致性引擎打通：模板值是**等价词表**的正式来源（选中模板后，跨单 diff 不再误报）。
- **数据**：新表 `tenant_clause_templates`（tenant_id/team_id、doc_types[]、name、text_zh、text_en、sort、is_active）——**迁移 +1**；不引入外部依赖。
- **后端**：CRUD 4 端点（team admin 可写、成员可读）；默认 6 类内置模板（首次访问懒创建或迁移种子）。
- **前端**：设置页面板 + 单证表单条款控件（复用 `Select`/`Textarea`）。
- **不做**：不自动改写历史单据；不做条款版本管理（v2 再议）。

### W2 · 行项批量编辑（中等投入）
- **做什么**：行项表格支持多选 → 批量改「规格/单价/数量/单位/原产国」；支持按产品筛选后整组改；
- **交互**：勾选行 → 顶部出现批量条 → 选择要改的字段 → 输入新值 → 预览影响（受影响行数/金额变化）→ 确认；
- **安全**：改数量/单价后**金额仍由 qty×price 推导**（A7 铁律），批量改只改输入项，不改金额字段；改完标记 `unconfirmed` 触发事实复核（符合 A7 签发闸门）。
- **实现**：纯前端状态机 + `PATCH /trade-docs/{id}` 现有通道；**不加后端端点**（若后续要"跨单批量改"再加）。
- **验收**：30 行单批量改单价，一次 PATCH、行金额全部同步、事实层标 unverified、签发被拦直到确认。

### W3 · 金额联动校验（小投入，增强体感）
- **做什么**：编辑面板顶部加"整单金额摘要条"——行合计 / 合计/大写 / 与上游订单差额（有上游时）；
- **联动**：改 qty/price 即时重算（前端 `Decimal` 同口径，避免浮点），超容差红标并提示「与上游订单差 X」；
- **只读**：摘要条**不可编辑**（避免绕过 A7 推导），点击可展开逐行差异。
- **实现**：复用 `kaas_common.trade_doc.rules` 的口径（前端按同一规则实现一份纯函数 + 共享测试向量）。

## 4. 风险与边界

- **风险 1：条款模板覆盖已编辑字段** → 默认"只填空字段，不覆盖非空"，覆盖必须显式确认；
- **风险 2：批量改破坏金额推导** → 只允许改 qty/price 等输入项，金额字段只读；A7 闸门天然兜底；
- **风险 3：模板化后一致性判定变宽** → 模板值必须进等价词表（W1 与 A7 打通），否则"模板 vs 手填"仍报冲突；
- **边界**：不做富文本条款、不做条款审批流、不做跨单批量改、不改历史单据。

## 5. 验收标准（可测）

1. 选条款模板 → 中英双语回填且进等价词表；跨单 diff 对模板值不误报；
2. 30 行批量改单价 → 1 次 PATCH、行金额/合计同步、事实层 unverified、签发被拦；
3. 金额摘要条与后端合计逐分一致（测试向量覆盖汇率/容差边界）；
4. 全部改动落 payload 且确认后不可改写（A7 不变）。

## 6. 需要你拍板的点

1. **条款库归属**：租户级（全团队共用）还是团队级（各团队独立）？默认团队级（与产品配置同口径）。
2. **内置默认模板**：要不要我预置 6 类（FOB/CIF 付款、装运、检验、索赔、不可抗力、仲裁）中文+英文？预置会带入业务口径，需你确认可用。
3. **W1/W3/W2 顺序**是否同意（先条款模板，再金额条，最后批量编辑）。
