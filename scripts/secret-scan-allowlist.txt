# 明文凭据扫描 allowlist（scripts/check-secrets.mjs 读取；STRUCTURAL_DEBT.md §6.4）
#
# 纪律（同 ui:patterns 的 ALLOWLIST，按「规则 + 文件」收窄，不做整文件无差别豁免）：
#   · 只允许两类登记：① 语义词明明是假的（测试假值 / 文档示例）；② 真实遗留但修复不在本批范围。
#   · 每行格式：<glob> <规则|*> # 原因 —— 原因为空或规则名未知 ⇒ 扫描器 exit 2（fail closed）。
#   · 原因必须写「为什么不是真实凭据 / 为什么必须留」，并尽量点明值是什么；禁止只写「误报」。
#   · 报告里会单独打印 allowlist 命中的 文件:行 + 规则 + 原因（不静默）；tree 模式下还会点名未命中的登记。
#   · 值已轮换/删除、或测试改成占位值后，**必须删行**（否则 tree 模式会提示过期登记）。
#   · 通配规则 * 只应给自测文件用（其正例必须包含真形状假值；否则用具体规则收窄）。
#
# 规则名（与脚本 RULES 一致）：private-key / aws-access-key / github-pat / notion-token / neon-token /
#   postgres-dsn / resend-key / openai-key / slack-token / generic-secret
