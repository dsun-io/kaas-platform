# orchestrator / worker 路由对等 —— 允许「线上缺失」的路由清单
#
# 由来：orchestrator 与 worker 是两套代码，历史多次出现「本地有、线上 404」。
# 本文件是**棘轮**：只有登记在案的路由才允许缺失；一旦 worker 补上了，
# 对应行必须删掉（scripts/route-parity.py 会把过期登记判为失败）。
#
# 格式：METHOD /path   # 原因
#   · 原因里含「待补」= 承认这是**缺口**（不是故意不做）。脚本每次运行都会
#     把这些债单独打印出来，避免烂在文件里；补完后请删行。
#   · 原因不含「待补」= 线上**故意不做**（平台运维/本地运行时/依赖 Pyodide 跑不了的东西）。
#
# 证据与分类详见 docs/ROUTE_PARITY_2026-10-10.md
# 更新：python scripts/route-parity.py --update  （更新后必须人工复核原因）
