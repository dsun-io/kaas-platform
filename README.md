## 分支策略（v1.0）

本项目严格遵守 [Git 分支策略与合并规范](.qwen/GIT_BRANCH_STRATEGY.md)：

- **main**：永远可交付，只接受通过 Nano + David 验收的功能分支
- **feat/***：功能开发分支，一任务一分支
- **fix/***：Bug 修复分支
- **docs/***：纯文档任务分支
- **archive/***：废弃但保留参考的分支

**禁止**：
- ❌ 直接 push 到 main
- ❌ 长期功能分支（> 2 周不合并）
- ❌ develop/staging 等长期开发分支
